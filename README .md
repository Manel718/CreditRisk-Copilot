# Agent Risk & Data
Agent IA d'audit de données de crédit : un LLM choisit et enchaîne des outils
Pandas (valeurs manquantes, aberrantes, taux de défaut...) à partir de questions
en français. Les données restent sur la machine : le LLM ne voit que des résultats agrégés.

Statut : version 1 en cours (RAG sur la documentation IFRS 9 à venir).
